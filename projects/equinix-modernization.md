# Hybrid-Cloud Interconnection Modernization

## Context

A large federal organization was modernizing connectivity between on-premise environments and AWS, Azure, and GCP through cloud-interconnection services.

## Matthew's contribution

Matthew served as Technical Product Owner and engineering lead across customer solution development, stakeholder coordination, and operating-model design.

He:

- Helped guide hybrid-cloud interconnection strategy.
- Coordinated networking, cloud, security, business, engineering, executive, and vendor stakeholders.
- Led customers through development of interconnection solutions and operating-model decisions.
- Supported funding, period-of-performance, resource-reuse, and delivery planning.
- Conducted cross-organization technical discovery to compare interconnection approaches.
- Created a GitLab repository template for Terraform-supported provisioning.
- Designed a proposed multi-tenant governance model using organizationally isolated connectivity structures analogous to cloud accounts and subscriptions.
- Supported planning for secure transfer of large datasets for downstream analytics and machine-learning use cases.
- Maintained awareness of routing-security concepts including RPKI, route-origin validation, and AS-path filtering.

## Technical environment

Equinix Fabric, Equinix Network Edge, AWS Direct Connect, Azure ExpressRoute, Google Cloud Interconnect, AWS, Azure, GCP, BGP, IPsec, MACsec, VPN patterns, Terraform, GitLab, object storage, DNS, routing, and enterprise networking technologies.
