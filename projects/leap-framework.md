# LEAP Framework

## Context

LEAP stands for **Layered Execution & Alignment Protocol**. It is a public software-delivery framework for turning rough intent into pressure-tested, source-grounded plans and safe, bounded coding-agent handoffs.

The documented lifecycle is:

`LEAP Charter -> LEAP Recon -> LEAP Prompt -> Implementation -> Validation/Handoff`

The framework also defines a documentation hierarchy spanning Mission / Project Charter, Strategic Outcome, Initiative, Delivery Unit, and Build Unit, together with operational prompts, templates, schemas, materiality guidance, dependency/contract recon, and maintainer/user documentation.
