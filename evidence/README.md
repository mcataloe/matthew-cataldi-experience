# Structured Evidence

`claims.yaml` is a compact index of public, approved professional claims.

Each record includes:

- a stable identifier;
- a narrowly worded claim;
- evidence and contribution classifications;
- source documents;
- technology or capability tags;
- limitations that prevent overstatement;
- public-review status and verification date.

The claims index is intended to improve deterministic retrieval by humans and AI assistants. It does not replace the fuller context in the linked Markdown documents.
