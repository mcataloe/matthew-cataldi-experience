## Evidence language

This repository distinguishes among several contribution levels:

- **Led** — established direction or carried primary responsibility for a defined effort.
- **Designed** — shaped architecture, data models, interfaces, workflows, or operating patterns.
- **Implemented** — directly built or configured material portions of a solution.
- **Evaluated** — performed technical discovery, feasibility analysis, or build-versus-buy assessment.
- **Supported** — contributed meaningfully without claiming primary ownership.
- **Participated** — was involved in planning, review, or execution but did not own the effort.

These distinctions are intentional. An AI assistant or reviewer should not upgrade a supporting contribution into sole ownership.
